### 3. ATTACK VECTORS & SCENARIOS

**Vector 1: Dependency Exploitation**
```
Attack Chain:
1. Attacker identifies axios vulnerability in package.json
2. Crafts malicious request exploiting SSRF vulnerability
3. Accesses internal services (metadata endpoints, databases)
4. Exfiltrates sensitive data or pivots to other systems

Impact: HIGH - Full system compromise possible
Mitigation: Update dependencies, implement egress filtering
```

**Vector 2: Prototype Pollution via Lodash**
```
Attack Chain:
1. Attacker sends crafted JSON payload
2. Lodash merge/set functions process malicious input
3. Object prototype is polluted with attacker-controlled properties
4. Application logic is subverted, potential RCE

Impact: HIGH - Code execution, privilege escalation
Mitigation: Update lodash, implement input validation
```

**Vector 3: Log Injection/Information Disclosure**
```
Attack Chain:
1. Attacker triggers error conditions
2. Console.log statements expose sensitive data
3. Logs are accessed via log aggregation or error reporting
4. Credentials, API keys, or PII are harvested

Impact: MEDIUM - Credential theft, privacy violation
Mitigation: Remove console.log, implement secure logging
```

**Vector 4: Zip Slip via Unzipper**
```
Attack Chain:
1. Attacker uploads malicious archive
2. Unzipper extracts files with path traversal sequences
3. Malicious files written outside intended directory
4. Code execution via overwritten application files

Impact: CRITICAL - Remote code execution
Mitigation: Update unzipper, validate extraction paths
```

**Vector 5: LLM/Prompt Injection**
```
Attack Chain:
1. Attacker crafts malicious input for LangChain processing
2. Prompt injection bypasses intended AI behavior
3. AI reveals system prompts, executes unintended actions
4. Data exfiltration or system manipulation

Impact: MEDIUM-HIGH - Data leakage, unauthorized actions
Mitigation: Input sanitization, output validation, prompt hardening
```
